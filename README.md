## About

This task contains 8 core Python programs that test basic logic and coding fundamentals. All the programs are written in a single file, `task1.py`, using basic Python syntax (input, if-else, loops and string slicing).

## How to Run

1. Make sure Python is installed (`python --version`).
2. Open a terminal in this folder.
3. Run:

```
python task1.py
```

The programs run one after another, so enter the input values when asked.

## Programs

### 1. Sum of Two Numbers
Takes two numbers as input and prints their sum.

```
Enter first number: 15
Enter second number: 25
Sum of two numbers is: 40
```

### 2. Odd or Even Checker
Checks if a number is odd or even using the `%` operator.

```
Enter a number: 17
The number is Odd
```

### 3. Factorial Calculation
Finds the factorial of a number using a `for` loop.

```
Enter a number: 5
Factorial of 5 is: 120
```

### 4. Fibonacci Sequence
Prints the first `n` numbers of the Fibonacci series.

```
Enter the number of terms: 7
Fibonacci Sequence:
0 1 1 2 3 5 8
```

### 5. String Reverse
Reverses a string using slicing (`[::-1]`).

```
Enter a string: Python
Reversed string: nohtyP
```

### 6. Palindrome Check
Checks if a word is the same forward and backward.

```
Enter a word: madam
The word is a Palindrome
```

### 7. Leap Year Check
Checks if a year is a leap year using `if`, `elif` and `else`.

```
Enter a year: 2024
It is a Leap Year
```

### 8. Armstrong Number
Checks if the sum of each digit raised to the power of the number of digits equals the number itself.

```
Enter a number: 153
It is an Armstrong Number
```

Example: 153 = 1³ + 5³ + 3³ = 1 + 125 + 27 = 153
